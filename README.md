# Learning JS Testing 🧪

A hands-on project focused on mastering the fundamentals of **Unit Testing** in JavaScript using the industry's most popular libraries.

## 🎯 Purpose

The goal of this project is to learn how to write reliable tests for JavaScript functions, covering basic logic, edge cases, and error handling. It serves as a playground to compare and implement testing with both **Jest** and **Vitest**.

## 🛠 Tech Stack

- **JavaScript (ES Modules)**
- **Jest**: The industry-standard testing framework.
- **Vitest**: A modern, blazing-fast testing unit powered by Vite.

## 🚀 Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run Tests:**
   - Run all tests (Jest + Vitest):
     ```bash
     npm test
     ```
   - Run only Jest tests:
     ```bash
     npm run test:jest
     ```
   - Run only Vitest tests:
     ```bash
     npm run test:vitest
     ```

## 📚 What I'm Learning

- **The AAA Pattern:** Arrange, Act, Assert.
- **Error Testing:** How to capture and assert thrown exceptions.
- **Environment Setup:** Configuring dual-testing environments for ESM.
- **Naming Conventions:** Writing descriptive and professional test cases.
